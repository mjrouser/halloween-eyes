# Test Gags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trigger a specific performance on demand for testing: `?gag=<name>` at a desk, and a "Test a gag" row on the phone control page for the Pi.

**Architecture:** The director gains an optional `cfg.testGag = { name, at, expires }` that, inside its span, loops one performance (full performance, 4 s pause, repeat) as a pure function of the clock. The page builds that object either from the URL (desk: `at: 0`, no expiry) or from two new config keys `testGag` / `testGagAt` that the server schedules 5 s ahead (Pi: 2-minute expiry). Every layer drops unknown names.

**Tech Stack:** Vanilla ES modules, `node --test` (Node 22 via `nvm use`), Python 3 stdlib server, `pytest`. Zero third-party dependencies.

**Spec:** [docs/specs/2026-10-05-test-gags-design.md](../specs/2026-10-05-test-gags-design.md)

## Global Constraints

- No `Math.random()` anywhere in show logic. Enforced by `tools/check-no-random.sh`.
- Both eyes share ONE timeline. A test gag is one performance for both eyes, never per eye.
- The show must never depend on the control channel. A failed poll, or a missing/unknown `testGag`, is a no-op, never an error state.
- Zero third-party dependencies. Node 22 via `nvm use`; Python 3 stdlib only. Tests are `node --test` (no path argument) and `.venv/bin/pytest tests/`.
- Every trigger is scheduled ("gag X from time T"), never "play now".
- Tunables: pause between loops **4000 ms**; expiry on the Pi **120000 ms** after `testGagAt`; server lead `SCHEDULE_LEAD_MS` (5000 ms, existing).
- Valid names: the seven in `GAG_NAMES` + `REACTION_NAMES` (`public/js/poses.js`). `idle` is not a performance.
- Off by default. `config.default.json` is not changed.
- Code freeze: Wednesday 2026-10-28.
- American spelling in all user-facing text and comments.
- **Commits:** do not commit until the user says so. Each task's last step is "commit when approved".

## Review Focus

1. **A name that is an `Object` prototype key** (`toString`, `__proto__`, `constructor`) from the URL or config. Expected: ignored, normal show. A bare `PROFILES[name]` lookup is truthy for these. Pinned in Task 1.
2. **`testGag` set but `testGagAt` missing or not a number** (hand-edited or old config). Expected: no test plays (it counts as long expired), normal show. Pinned in Task 1 (`testGagFrom`) and Task 3.
3. **A style change after a test** (palette or shape posted later). Expected: the old test does not replay, because `testGagAt` is untouched. Pinned in Task 2.
4. **The exact expiry instant.** Expected: at `tMs === expires` the normal show runs. Pinned in Task 1.
5. **A window that reloads mid-test** (crash, service restart). Expected: it rejoins the loop in phase with the other window, because the state depends only on `tMs` and config. Pinned in Task 1 (same-input determinism across a loop boundary).

```js
/** Test gags (docs/specs/2026-10-05-test-gags-design.md). */
export const TEST_GAG_PAUSE_MS = 4000;     // idle beat between loops
export const TEST_GAG_EXPIRY_MS = 120000;  // a test started from the phone stops by itself

const isPerformance = (name) => PERFORMANCE_NAMES.includes(name);

/**
 * The cfg.testGag object for showState, or undefined for the normal show.
 * The URL (desk) wins and never expires; `at: 0` aligns its loop to the clock,
 * so two desk windows with the same ?gag= stay in sync. From config (the Pi),
 * the loop starts at testGagAt and expires two minutes later.
 */
export function testGagFrom({ urlGag, testGag, testGagAt }) {
  if (isPerformance(urlGag)) return { name: urlGag, at: 0, expires: Infinity };
  if (isPerformance(testGag) && Number.isFinite(testGagAt)) {
    return { name: testGag, at: testGagAt, expires: testGagAt + TEST_GAG_EXPIRY_MS };
  }
  return undefined;
}

/**
 * Which performance is on now: a test gag inside its span, else this cycle's.
 * `active` is false between performances (and in a test gag's pause).
 */
function currentPerformance(tMs, cfg) {
  const test = cfg.testGag;
  if (test && isPerformance(test.name) && tMs >= test.at && tMs < test.expires) {
    const duration = profileDuration(test.name);
    const elapsed = (tMs - test.at) % (duration + TEST_GAG_PAUSE_MS);
    return { name: test.name, active: elapsed < duration, elapsed };
  }
  const cycle = Math.floor(tMs / cfg.cycleMs);
  const intoCycle = tMs - cycle * cfg.cycleMs;
  const perf = performanceFor(cycle, cfg);
  const elapsed = intoCycle - perf.startAt;
  return { name: perf.name, active: elapsed >= 0 && elapsed < perf.duration, elapsed };
}
```

```python
import re

from server.serve import PERFORMANCE_NAMES, SCHEDULE_LEAD_MS


def test_performance_names_match_the_show():
    """The server's names are a copy of poses.js. Fail if the two drift apart."""
    source = (Path(__file__).parent.parent / "public/js/poses.js").read_text(encoding="utf-8")
    names = []
    for const in ("GAG_NAMES", "REACTION_NAMES"):
        body = re.search(rf"export const {const} = \[(.*?)\]", source, re.S).group(1)
        names += re.findall(r"'([^']+)'", body)
    assert list(PERFORMANCE_NAMES) == names


def test_test_gag_off_by_default(running):
    base, _ = running
    _, body = get(f"{base}/config.json")
    assert json.loads(body)["testGag"] == "off"


def test_accepts_each_test_gag_and_schedules_it(running):
    import time

    base, _ = running
    for name in PERFORMANCE_NAMES:
        status, body = post(f"{base}/config", {"testGag": name})
        assert status == 200, body
        assert body["testGag"] == name
        lead_ms = body["testGagAt"] - time.time() * 1000
        assert 2000 < lead_ms <= SCHEDULE_LEAD_MS + 100, f"lead {lead_ms}ms"


def test_rejects_unknown_or_non_string_test_gags(running):
    base, _ = running
    for bad in ["nope", "idle", "toString", "", 1, True, None, ["crossEyed"]]:
        status, _ = post(f"{base}/config", {"testGag": bad})
        assert status == 400, f"accepted {bad!r}"


def test_stop_turns_the_test_gag_off(running):
    base, _ = running
    post(f"{base}/config", {"testGag": "crossEyed"})
    status, body = post(f"{base}/config", {"testGag": "off"})
    assert status == 200
    assert body["testGag"] == "off"


def test_a_later_style_change_does_not_replay_the_test(running):
    base, _ = running
    _, first = post(f"{base}/config", {"testGag": "crossEyed"})
    _, later = post(f"{base}/config", {"palette": "green"})
    assert later["testGagAt"] == first["testGagAt"], "testGagAt must only move when a test is posted"


def test_load_config_ignores_a_non_numeric_test_gag_at(tmp_path):
    path = tmp_path / "config.json"
    path.write_text(json.dumps({"testGag": "crossEyed", "testGagAt": "soon"}), encoding="utf-8")
    config = load_config(path)
    assert config["testGag"] == "crossEyed"
    assert config["testGagAt"] == 0
```
